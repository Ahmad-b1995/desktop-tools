# Changelog

## 6 (2026-10-29)

- Clip is now written in TypeScript (`src/`), type-checked against the GNOME 50
  type definitions; the shipped JavaScript is generated by `tsc` and stays
  readable for review.
- Clip ships without default shortcuts, as extensions.gnome.org requires for
  clipboard tools. `make install` still sets Super+V and Super+Shift+T unless you
  chose your own, and the settings have a Shortcuts section to change them.
- Adding an OCR language no longer runs `apt-get` as root from the settings:
  each language shows its install command with a copy button, and a refresh
  button picks up what you installed.
- Any open history popup or text selection closes when the screen locks.
- The default OCR language is English only (was English + Persian).

## 5 (2026-10-09)

- Clip: fix a crash that logged the user out when choosing an image from the
  history. The image buffer from `St.Clipboard.get_content()` is only valid
  during the callback; Clip kept it, and re-copying it later made
  `st_clipboard_set_content` read freed memory (SIGSEGV in GNOME Shell). Clip
  now copies the bytes it receives and refuses to re-copy an image whose buffer
  no longer matches what was captured.
- tests/image-roundtrip.sh: regression test in a nested GNOME Shell, so a crash
  can never take down the real session.

## 4 (2026-09-29)

- Clip: images (screenshots, copied pictures) are recorded too, with a
  thumbnail, size and dimensions; selecting one puts the image back on the
  clipboard. Up to 20 images, 30 MB each, memory only; searchable as
  "image" or "screenshot".

## 3 (2026-09-29)

- Clip: the settings gear and mouse clicks on entries use their own release
  handlers (GNOME 50 no longer delivered St.Button clicks inside the popup);
  Ctrl+, opens settings from the keyboard.
- pick: `install.sh` stores the screenshot permission for `com.ahmadcodes.Pick`.
  GNOME 50 refused pick's silent screenshot and never showed the permission
  dialog, so the picker opened and closed without doing anything.

## 2 (2026-09-29)

- Clip: works on GNOME 50. Super+V crashed because `Clutter.Grab.get_seat_state`
  and `Meta.Display.set_cursor` no longer exist; Clip now uses the GNOME 50
  equivalents and keeps the GNOME 49 path.
- Clip: an error while opening the popup or the region selector can no longer
  leave an invisible overlay holding the keyboard.

## 1 (2026-09-28)

First release.

- Clip: in-memory clipboard history with search, pinning and paste on select
- Clip: region text capture with Tesseract, frozen screen, English and Persian by default
- Clip: preferences to choose and install OCR languages
- pick: color picker with magnifier, HEX, RGB and HSL output, multi-monitor
